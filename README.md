# MQ Squashers Android App
MQ Squashers Android app, using [Hotwire Native](https://native.hotwired.dev/android/getting-started) project.

The app wraps the https://mqsquashers.com website on a Hotwire Webview and adds:

- Bottom Navbar with basic action to navigate the web.
- Top Toolbar with title of pages and sections.
- ...
